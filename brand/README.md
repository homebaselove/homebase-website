# Homebase brand kit

The guidelines are the slide deck at homebase.love/brandkit
(`public/HomebaseBrandKit.pdf`), linked from the footer: logo, construction,
clear space, colour, type, interface, voice, misuse, and Base and social
specs. The site serves this folder as `public/HomebaseBrandKit.zip`.

Every file here but this README is generated by `bun scripts/brand-kit.ts`
from the dot maps in `src/ui/dots.ts`, so the logo matches the site exactly.
Edit the dot maps or the script, never the files.

## Sending the logo

For partners such as Base, send:

- `logo/svg/homebase-stacked-blue.svg` and `logo/png/homebase-stacked-blue.png`
- `logo/svg/homebase-mark-blue.svg` and `logo/png/homebase-mark-blue.png`
- `icon/homebase-app-icon-1024.png` (1024 × 1024, no alpha)

## Colours

| Name | Hex | Use |
| --- | --- | --- |
| Homebase Blue | `#0000FF` | Logo, masthead, primary buttons |
| Paper White | `#FFFFFF` | Backgrounds |
| Ink | `#18181B` | Text |
| Pressed Blue | `#0000CC` | Hover only, never in the logo |

Type is [Lato](https://fonts.google.com/specimen/Lato), 300 to 900.

## Layout

- `logo/{svg,pdf,png}/homebase-{stacked,horizontal,mark,wordmark}-{blue,white,ink,white-on-blue}`:
  PNGs are transparent (except white-on-blue) and 4096 or 8192 px on the long side.
- `icon/`: app icon, avatar, splash, favicon.
- `social/`: Open Graph, X header.
- `colors.css`, `colors.json`: the colour tokens.
